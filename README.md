# แอประบบเบิก OT (PWA บน GitHub Pages)

แอปสำหรับโทรศัพท์ iPad แท็บเล็ต และคอมพิวเตอร์ — ติดตั้งลงหน้าจอหลักได้ มีไอคอนของตัวเอง เปิดเต็มจอเหมือนแอป
ตัวแอปเป็น "กรอบ" ที่เปิดระบบเบิก OT (Google Apps Script) เดิมไว้ข้างใน ข้อมูลทั้งหมดยังอยู่ที่ Google Sheets เหมือนเดิม

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเปิดแอป + กรอบเปิดระบบ OT + แถบชวนติดตั้ง |
| `config.js` | **ที่ต้องแก้** — ใส่ URL ของเว็บแอป Apps Script |
| `manifest.webmanifest` | ชื่อแอป ไอคอน สี (ทำให้ "ติดตั้ง" ได้) |
| `sw.js` | Service worker — ให้เปิดแอปได้เร็วและติดตั้งได้ |
| `icons/` | ไอคอนแอปทุกขนาด (Android, iPhone/iPad, คอม) |

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1. เตรียม Apps Script
1. วาง `Code.gs` และ `Index.html` เวอร์ชันล่าสุดทับของเดิม
2. **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ)**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคนใน mahidol.ac.th**
   - เวอร์ชัน: **New version** → Deploy
3. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 2. ใส่ URL ใน `config.js`
```js
GAS_URL: 'https://script.google.com/a/macros/mahidol.ac.th/s/xxxxxxxx/exec',
```

### 3. ขึ้น GitHub Pages
1. เข้า github.com → **New repository** → ตั้งชื่อ เช่น `ot-app` → เลือก **Public** → Create
2. กด **Add file → Upload files** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons`) → **Commit changes**
3. ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** → **Save**
4. รอ 1–2 นาที จะได้ลิงก์แอป เช่น `https://ชื่อบัญชี.github.io/ot-app/`

> ลิงก์นี้คือ "ลิงก์แอป" ที่แจกให้เจ้าหน้าที่ใช้ติดตั้ง

## วิธีติดตั้งแอปบนอุปกรณ์

| อุปกรณ์ | วิธีติดตั้ง |
|---|---|
| **Android** (Chrome) | เปิดลิงก์แอป → กด **ติดตั้ง** ที่แถบด้านล่าง (หรือเมนู ⋮ → **ติดตั้งแอป**) |
| **iPhone / iPad** (Safari) | เปิดลิงก์แอปใน **Safari** → ปุ่มแชร์ ⬆️ → **เพิ่มไปยังหน้าจอโฮม** |
| **แท็บเล็ต Android** | เหมือน Android |
| **คอมพิวเตอร์** (Chrome / Edge) | เปิดลิงก์แอป → ไอคอนติดตั้ง ⊕ ที่ช่อง URL |

หลังติดตั้งจะมีไอคอน **"เบิก OT"** บนหน้าจอหลัก กดแล้วเปิดเต็มจอเหมือนแอป

## หมายเหตุสำคัญ

- **อัปเดตระบบ:** แก้ `Code.gs` / `Index.html` แล้ว Deploy ตามปกติ — แอปที่ติดตั้งไว้ได้ของใหม่ทันที ไม่ต้องติดตั้งใหม่
- **iPhone / iPad:** iOS ไม่อนุญาตให้ลงชื่อเข้าใช้ Google "ภายในกรอบ" ของแอป ถ้าเปิดแล้วค้าง แอปจะขึ้นปุ่ม
  **"เปิดระบบแบบเต็มหน้าจอ"** ให้เอง — ติ๊ก "เปิดแบบเต็มหน้าจอทุกครั้ง" ไว้ ครั้งต่อไปจะเปิดได้ทันที
- **ถ้าเปลี่ยนไอคอน / ไฟล์ในแอป:** แก้เลขเวอร์ชันใน `sw.js` (`ot-app-v1` → `ot-app-v2`) เพื่อให้เครื่องที่ติดตั้งไว้โหลดไฟล์ใหม่
- **ความปลอดภัย:** repo เป็น Public แต่มีแค่ URL ของเว็บแอป ซึ่งเปิดได้เฉพาะบัญชี @mahidol.ac.th — ข้อมูล OT ไม่ได้อยู่ใน GitHub
